## 场景中实际看到了什么

| 对照变量 | 答案表现 |
| --- | --- |
| 队友已开始移动／仍在清线 | 都不把“能来”当“已经到场”；分别检查继续移动、清线与离线成本 |
| 关键装备持有／等值现金未花 | 前者保留入口压力；后者考虑安全补装，并接受可能错过窗口 |
| 本人／队友承担主要输出 | 前者更重视保留本人输出位置；后者允许本人在承接成立后承担先手 |
| 审计侧敌人位置改变 | 模型收到完全相同的可知输入，两份答案都不凭过期位置保证入口安全 |
| 打野控制与敌方中断组合改变 | 重新比较3v3；有控制时保留争取候选，承接受中断时不主动升级，均不由2v2标签断言胜负 |
| 中国单排／韩国组排经验标签 | 保留同样的当前事实约束；不把组排来源当成本局已沟通，也不靠地区标签反转策略 |
| 本人可独立完成有限目标／必须队友承接 | 前者明确立即完成有限观察并退出，不等清线队友；后者先保持阵型，等实际承接，排除当前独自尝试 |

## 修了三处

1. **状态不能冒充行动。** 旧检查器会接受“引用队友生命值，宣称已跟进”。现在必须匹配队友、动作键及对应行动观测；开始移动仍不证明到场和后续承诺。
2. **标签必须有明确含义。** 首轮模型把“保守建议有依据”写成`supported`，同时保留待满足条件。提示现在明确：存在前提、假设或未知配合时用`conditional`；推荐级标签还区分耗时是否齐备。不删除真实缺口来换取通过。
3. **排除项必须显眼。** 模型明确排除的“盲目独自前压”，此前仍显示普通候选标题。中文卡现在标明“已排除，不执行”，同时区别已具备条件与待条件满足。
