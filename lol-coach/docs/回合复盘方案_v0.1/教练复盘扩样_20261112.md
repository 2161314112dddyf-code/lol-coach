## 最值得改的三个判断

**一、把“有线权可以动”改成“这个人还能离线多久，多去一个人能改变什么”。** Tutu 复盘学员打龙时，指出中单帮了一下就走，再帮约五秒龙就能打完，兵也还没到中塔。另一个实战里，小龙没人争，中单赶去并未改变归属，中路却无人守，丢了两座塔。还有第三种情况：羽妹让带传送、塔下守得住的玛尔扎哈去接边线，奎桑提跟另外三人去大龙，因为正面缺人扛伤。对应的是多留、别去、指定谁去三种答案。工具要能同时算这个人离开的位置会发生什么，以及到达后他能补上哪项能力。[Tutu 打龙与接线 21:40](https://www.youtube.com/watch?v=M9YRvL-Caxg&t=1300s) · [无人争龙时中路失守 19:10](https://www.youtube.com/watch?v=HN2qjqeGAFM&t=1150s) · [羽妹四一分工 30:56](https://www.bilibili.com/video/BV1Di421e763/?t=1856)

**二、把“队友在旁边”拆成能否同时打到、会否一起被控。** CoreJJ 的牛头先手示意里，牛头够得着，射手落在后面，两个敌人都能先打牛头。换一个真实投稿，金克丝紧贴日女又给了芮尔一次控两人的机会。两项要求可以同时成立：两人能在控制结束前打同一个目标，又给彼此留出横向间距。这个例子比给“附近队友数量”再加权更能指导下路复盘。[CoreJJ 双人线 01:00](https://www.youtube.com/watch?v=v-ec5astbE0&t=60s) · [投稿回放章节 34:41](https://www.youtube.com/watch?v=ntpv1MPiK5E&t=2081s) · [教练原声 36:04–36:25](https://traffic.megaphone.fm/APO5188654790.mp3#t=2164,2185)

**三、区分“出现线索”“动作已交”和“下一回合还剩什么”。** 安欢欢先赞成趁补刀消耗，随后因对手马上升二而反对再次上前。陌路里给出两种处理。一种是假装补刀，等对手先交技能再收兵。另一种是取消抬手，直接走位。另一个学员龙前被迫用芸阿娜大招自保，之后到龙时人虽在场，己方两个大招都不在。Agent 给建议时需要说清楚，眼下能试探到哪一步、什么出现才继续、现在付出的代价会落在哪一波。[升二前后 02:47](https://www.bilibili.com/video/BV1rh411z7TS/?t=167) · [沙皇假动作 01:12](https://www.bilibili.com/video/BV16z421z7wY/?t=72) · [芸阿娜龙前复盘章节 31:27](https://www.youtube.com/watch?v=WE9I6GkyhBA&t=1887s)

**国服实局里，可以看到这个回合具体在哪里结束。** 一区大师腕豪判断对手可能来上半区补眼，先在入口等，抓到人之后才喊大龙。峡谷之巅的另一场，贝蕾亚看队友残血，放弃反石甲虫，准备刷 F6 等队友回补再接先锋。队友却留在外面阵亡，之前的先锋计划随即失效。前者适合检验 Agent 会不会提前把埋伏写成击杀，后者检验它会不会在队友阵亡后仍执行上一轮计划。[腕豪等人补眼 09:47](https://www.bilibili.com/video/BV1wqGf6KEEk/?t=587) · [贝蕾亚放弃反野 07:20](https://www.bilibili.com/video/BV1JeAweuEL5/?t=440)

## 一回合怎样交给 Agent 和 MCP

宿主冻结队伍、比赛时刻和上一回合计划。Agent 先提两个能执行的动作，指出区分它们的一个事实。程序只计算当时可知的数据，并返回证据和误差。Agent 才决定先做什么、放掉什么、出现什么改选。结果揭晓后再评价这次判断。下表是这次扩样对[原有接口设计](自建复盘Agent_20261112.md)的修改建议。

| 教练会追问什么 | MCP 应该返回什么 | 检验方法 |
| --- | --- | --- |
| 接完线再走，哪边先到？多留一个人能加快多少？ | 并列返回清完或放线、己方后排兵与敌方下一波到塔、本人往返、目标完成的时间区间。在有依据时给有此人和无此人两种完成区间。同时列出留守者和失守的线。 | 同一局面只提前敌方兵线到塔。看“再帮几秒”是否缩短。再只改无关的装备栏排列，原建议应当保持。 |
| 双方谁真的接得上？ | 分人给出在技能窗口内第一次能作用到目标的时刻、控制或伤害的作用范围、同吃范围控制的风险。队友已向此处移动和愿意跟进分别记录。 | 后移射手但保持辅助距离不变，再横向移开射手同时保留输出范围。两次调整应该导向不同判断。 |
| 此刻哪个技能真的交了？若没人来接，怎么出去？ | 区分可见施法、走位线索、无法确认的冷却，关联本人的进场与退场手段。视野查询返回入口、上次观察时间和未覆盖路径。 | 拿掉沙皇身后的沙兵，或移除佛耶戈这次扫描。模型应重估退路或路线暴露风险，不能凭敌方事后位置补答案。[沙皇学员回放](https://www.youtube.com/watch?v=dkPbEzPbwcw&t=2114s) · [PerryJG 扫描后绕侧 04:01](https://www.youtube.com/watch?v=lvI6VhTQlo0&t=241s) |
| 什么让上回合的计划失效？ | 保存承诺过的动作、到期时间和失效信号。新片段只更新变动的条件，如守方露头、队友转向或关键技能交出。 | 隐去女警重新在中路露头的证据，卡莎应暂缓“上塔没人”的断言。在另一份输入恢复露头，才重开下一波推进。[卡莎带边与回撤 11:25](https://www.youtube.com/watch?v=OM14vGC9C8A&t=685s) |

**第一项工程验收**沿用现有十人回放。让现有 Agent 和新增时间计算的版本都回答“中单该留下还是先走”。复用同一时刻、同一队伍、同一预算。先检查有无越过视野或时间边界，再检查有没有算出会放掉哪波兵、建议是否随关键条件改变。两种合理动作都能拿分，但理由必须能在当时找到证据。区间重叠且不足以定优劣时，能给出条件分支也算答对。精确秒数、伤害或胜率没有实测依据时留空。按整部作品、同一场对局和同一教学系列划分开发例与盲评例，避免相邻片段泄题。教练观点与干预题留在评测端。这里交付的是选段和验收设计，扩样后的模型正确率仍待实测。[Agent 评测方法](https://www.anthropic.com/research/demystifying-evals-for-ai-agents) · [面向 Agent 的工具设计](https://www.anthropic.com/research/writing-tools-for-agents) · [MCP 工具规范](https://modelcontextprotocol.io/specification/2025-11-25/server/tools)

## 样本怎么读

- 按主选段分，有 **36 部回放复盘、12 部实战口述或现场指导、15 部教学示范、3 部赛事分析**。回放复盘含讲者回看自己、学员、投稿者或他人的具体局面。教学演示与赛事讲评只能支持各自呈现的判断。时间都是播放器或注明的节目音轨进度。
- B 站稿按公开原声音轨的选段转写并抽查画面。YouTube 按原上传核对标题和频道，内容分别由公开时间字幕、同片镜像的原声与内嵌字幕，或同节目发行者的音频核读。6 部 Broken By Concept 节目使用作者标注的 YouTube 章节与另列的音频选段，二者剪辑不同。每条的核对方式保存在清单里。
- 10 部的作者在标题或说明中明确标注国服、一区、电一或峡谷之巅。中文授课与对局服务器分开登记。样本覆盖五个位置，按决策类型有目的地选片；羽妹与 Gen.G 训练营的多部作品以及 Skill Capped 的同系列课程有相关性。因此这些数目适合说明覆盖面，不能推断高手在排位中选择每种打法的比例。
- 原作与搬运只算一次。同片的不同回合可各留证据。一个 CoreJJ 镜像的简介链接指向 EP04-1，但片内标题、内容和另一份镜像均是 EP04，故只并入 EP04。上轮的课程逐字稿另列。下方链接用中文概括所讨论的选择，官方原标题保存在 JSON 的 `source_title`。
