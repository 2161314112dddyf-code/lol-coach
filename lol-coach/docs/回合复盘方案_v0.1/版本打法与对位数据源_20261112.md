## 复盘 Agent 如何使用

- **能直接调用的渠道。** OP.GG 提供官方 MCP。本轮用 `lol_get_lane_matchup_guide` 固定卡牌中路，把对手从卡特换成劫。五行 `game_lengths` 和版本趋势完全相同，核心装样本和打法建议随对手改变。时光之杖→巫妖之祸→疾射火炮，对卡特的样本为 **291 胜/542 场**，对劫为 **315 胜/638 场**。这个工具的时长结果按英雄分路总体保留。返回趋势最新标签为 16.22，该工具未回显赛区和段位，也未提供指定历史补丁的入参。[OP.GG 官方 MCP 文档](https://github.com/opgginc/opgg-mcp)
- **适合人工复核的渠道。** LoLalytics 公开网页可核同版本、同路、特定对手的样本。其后端首页明确将该 API 限于本站访问者使用，项目自动调用优先选用已公开的 OP.GG MCP。[LoLalytics 接口说明](https://a3.lolalytics.com/)
- **能解释打法的渠道。** Mobalytics 的卡牌指南把等级、技能、推线与支援连起来，可作为教练判断的线索。复盘 05:20 的卡牌时，先查你是否到六、R 是否可用、中线是否能放、目标能否被接应。分时胜率无法代替这些本局事实。女警同一秒若面临近身威胁，就先复盘她当时可用的位移、输出位置和退路。[卡牌打法与等级节点](https://mobalytics.gg/lol/champions/twistedfate/guide)
- **方便横向查表的渠道。** Invade 在同一版本与位置下分别列出结局时长胜率、10/15 分钟补刀和经济等指标。中单卡牌在 16.22 翡翠以上、站方全部赛区的样本中，15 分钟平均少补约 **7.4** 个兵，仍多约 **148** 金。这是所有中路对手合计，前面对卡特的数字来自指定对位与另一段位。[时长表](https://invade.lol/stats?role=mid&view=length) · [早期对线表](https://invade.lol/stats?role=mid&view=early)

每条统计入库时要保留玩家英雄及位置、对手或搭档、补丁、赛区、段位、队列、指标定义、胜场及总场次、统计日、抓取日和来源。未给的维度留空。赛后用全补丁样本解释旧局时标明“回顾参考”。若用于模拟当时的决策或评测，只能用那一刻以前已有的统计快照。本次只核了来源，没有修改线上取数流程。
