# 国服研究如何落实到链路、场景与训练

2026-10-23 · ROUND-002-CN。配套[结论简稿](CN_REVIEW_FINDINGS.md)与[原实现规格](ROUND_PIPELINE_SPEC_V0_1.md)。下文为设计建议，不是新增已实现字段或已经通过的测试。

## 1. 每个时刻真正要组织的信息

分析顺序保持：**当时可知事实 → 本局各人职责 → 即将过期的机会 → 候选行动 → 配合与退出条件 → 下一回合状态**。

| 信息 | 建议字段 | 不允许的替代 |
| --- | --- | --- |
| 对局环境 | PC、地图/模式、build、日期、原大区、匹配池、队列、预组队范围、来源 | 中文作者或“国一”称号代替国服实局；队列代替实际开黑关系 |
| 各人职责 | 当前先手/主要伤害/保护/收割/带线；相关队友与对手；改变职责的状态 | 一个英雄或“野核”标签决定全局行动 |
| 行动窗口 | 触发事件、预计失效条件、本人及队友到达区间、敌方已知介入条件 | 固定每N秒一回合；事后真实到场时间冒充事前预测 |
| 配合状态 | 谁能离线、谁已经移动、需要谁提供何种能力、最迟何时到达、未响应备选 | 地图近就一定能来；打信号就已经约好；没信号就是没沟通 |
| 实际战力 | 已买装备、可知现金、关键状态、回补所需路径、版本兼容的机制 | 金币领先直接判能打；现金与装备等值替换 |
| 机会成本 | 本人/队友兵线、经验、营地、位置暴露、视野补给、下一资源准备 | 只算这次击杀金币；忽略队友为支援承担的损失 |
| 依据与缺口 | 观测/工具估计/作者经验/项目推断；来源版本、读取层级、待满足条件 | 标题、平台AI稿、观众评论变成已确认比赛事实 |

玩家段位、主玩位置、语音关系只用已有、合法且时间适用的信息；不追查私人资料，不猜隐藏MMR。缺失不阻断整份报告。区域视野或冷却未充分解码时，依赖它们的建议保留条件，其余分析继续。

## 2. 三个具体场景：答案应该怎样写

以下是**来源启发的教学条件题**，不是本轮新观看的三场国服比赛，不可计入真实局评测。没有虚构时间戳、经济差、成功率或技能数值。变化条件由本项目提出。

### 场景A：资源快刷新，队友有钱但没回补

出处：E03甜咖啡原文的资源准备讨论。这里仅借其因果结构，不复用S10装备和资源排序。

**题设**：己方下路正在处理塔前兵线，主输出尚未更新关键装备；打野已经靠近资源区。敌方可以先布置。队友能否清完回补后赶到还不确定。

**给玩家的答案**：

> 此时优先保留撤退空间，别把一个准备不足的资源回合变成必须接的团。先比较两条路：如果能帮助下路处理兵线、让其补装后仍赶得上，就把本回合改为准备和争取入口；若时间装不下这套动作，就准备让出资源，并核对另一侧是否有安全收益。对面露出可利用失误时再调整。

**分析需要补齐的决定性条件**：清线与回补/到达时间区间，资源紧迫性，敌方当时可知位置，已买装备与关键技能。另一侧收益同样要验证，不能自动写“换先锋”。资源是否必须争、是否有低风险拖延或抢夺方式，要按具体状态列为备选。

**向前复盘**：回看上一处可回补机会是否真实存在。若当时就没条件回城，不能把失败简单归为“贪”。后来打输了不证明此时所有参战选择都不合理。

### 场景B：辅助开到人，ADC正在收一大波线

素材入口：L08，羽妹Sup国服一区洛对派克，作者回复确认单双排；其题材适合此题，但**本题的兵线和具体站位为构造条件，未声称来自该录像**。

**题设**：辅助有开团机会，ADC尚未进入有效输出位置；双方关键技能与敌方支援尚需核对。

**给玩家的答案**：

> 开到人不等于此刻能打赢。先确认ADC能否在控制结束前形成有效输出，以及离线要丢多少兵。如果队友还在处理兵线，本次更适合保留威胁、保护其清线，再找能共同进场的窗口；如果对方暴露了不依赖ADC也能兑现的机会，可以另行比较。队友开始移动、敌方反制技能交出，都是重新评估的信号。

**反例**：控制和伤害足以独立完成行动、阻止对方越塔、ADC本来就能边移动边输出等情况，会改变优先级。不能把这张题变成“ADC没走就永远不能开”。决策时不知道对方后续支援会不会来，不能使用回放全知位置。

### 场景C：同一个薇古丝，到底先手还是留输出

出处：L03小雪呼呼的职责区分；具体机制由目标版本资料另查。

**题设**：只知道自己能找到进场角度还不足以决定。比较两组条件：队友在位并能承接；或者自己是主要伤害来源、其他队友尚不能跟进。

**给玩家的答案**：

> 先看你进场后由谁兑现。如果队友已在有效范围内且对方反制可应对，先手可以作为优先候选；若进场会让本队失去主要持续输出，先保持能输出和撤退的位置，等对方关键状态变化后再进。大招可用本身不是开团理由。

**这张题要让模型证明的能力**：推荐随双方条件变化，理由能指出变化的是队友承接、伤害职责或敌方反制，而不是机械地复述“法刺要切后排”。没确认冷却就不能写对手已经没有反制。

## 3. 经验卡与训练样本分两步

先保存短经验卡：`来源ID → 实际读到的主张 → 地区/队列/版本 → 成立条件 → 失效或反例 → 需要的游戏字段 → 允许的使用范围`。同作者不同地区、同视频不同片段分别打标签；原始发布日期不等于机制适用版本。

具备完整上下文和使用权限后，才形成训练候选：`截止t输入 → 2—3候选 → 可接受行动集合 → 支持事实 → 配合依赖 → 机会成本 → 中止条件`。原操作、作者解释、项目补写、后验结果分别存放。平台智能文稿只能帮定位内容，不能当教师答案。

优先检验的是：模型是否漏掉可见事实、缺少知识、忽略队友条件，还是不会比较机会成本。分别对应修状态、改检索、改提示/规则或后续训练，不能一律归为“缺微调”。原100个开发回合和后续训练数量仍为预算草案，本轮没有扩张数量门槛。

## 4. 在原R1—R6内增加六道有限对照题

均为待执行的构造对照题；每对只改变一项条件，其他信息固定。它们用于检验建议的敏感性和理由，**不算额外真实比赛**，也不强求每次变化一定令首选翻转。

| 题 | 唯一变化 | 应看到什么 | 对应验收 |
| --- | --- | --- | --- |
| C1 配合 | 队友已向入口移动／仍在处理兵线 | 更新到达条件和支援成本；必要时转备选；不能宣称已沟通一致 | R2/R4/R5 |
| C2 补装 | 同等累计收入，关键装备已购买／现金未花 | 重新判断可用能力及回补成本，不把两种状态视为同战力 | R2/R4 |
| C3 角色 | 本人是主要输出／队友可承担主要输出 | 解释进场责任、承接和失败代价的变化，保持对手约束 | R4/R5 |
| C4 可知性 | 敌人刚在本人可知视野露头／仅在全知回放露头 | 后者不进入决策事实，不能据隐藏位置保证安全 | R1/R2 |
| C5 线上与野区 | 固定2v2条件，只改变参战打野组合及已知状态 | 重新计算3v3条件，不能从2v2劣势直接判3v3必败 | R4/R5 |
| C6 经验环境 | 资料标中国单排／韩服或组排 | 正确分类与限制迁移；不能只因标签变化就无依据反转战术 | R2/R5 |

沿用原10局50回合的待批准规模；给首批实际国服样本单独分母，按队列/版本/分段报告覆盖。单排、组排或某分段缺样本时写未覆盖，不通过继续加量掩盖。各层必须说明样本量，不能由极小子集推断总体差异。
