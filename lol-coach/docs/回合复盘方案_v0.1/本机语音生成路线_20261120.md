# 本机语音生成路线

日期：2026-11-20。任务：LOCAL-VOICE-RESEARCH-01。状态：选型调研完成，模型运行与听感未验收。

## 已确定的目标

语音在用户本机生成，以 dot 的自然听感作为体验参照。先实现赛后复盘口播，沿用现有 Python agent、MCP、玩家视角与证据核验；不把语音要求擅自扩大为整个分析模型本机化。当前不训练、不微调，不使用云端语音 API 作为本地方案，也不要求用户补录游戏实验。

本轮只读查询：RTX 4060 Laptop，8188MiB 显存；31.70GiB 内存；驱动610.88。系统为此前会话核实的 Windows 11。没有模型速度或实际显存峰值数据。

## 建议选择

| 路线 | 可复刻的能力 | 当前机器的边界 |
| --- | --- | --- |
| IndexTTS-2.5，本轮首选试跑 | 参考音色、音色与情感分别控制、中文拼音读音、语速、本地 WAV | 官方模型卡约6GB显存；8GB有试跑依据。源码低显存短分段可能使长文接缝明显，尚未试听 |
| Qwen3-TTS 1.7B，音色对照 | CustomVoice 现成音色及语气指令；VoiceDesign 按文字设计音色，随后由 Base 复用参考音色 | 有公开代码和权重；8GB运行峰值与速度未知，不能按参数量宣称一定能跑。设计与复用模型顺序加载，避免同时常驻 |
| MiniCPM-o 4.5，后续研究 | 中文、英文原生全双工，持续听取输入并生成语音 | 官方 llama.cpp-omni 实时方案至少12GB显存，PyTorch全功能演示至少28GB；不作为本轮8GB目标 |

Qwen3-TTS 0.6B可作为显存不足时的轻量替代，但官方型号表未赋予0.6B情感指令控制，不把它当作1.7B能力等价版。CosyVoice3也有公开中文、情绪和流式方案，保留为后备；首轮不同时铺设多套运行环境。

未找到 GPT-Live 的官方本地权重发布依据。这里复刻的是自然语音能力及系统分工，不承诺复现 dot 的原模型、同一音色或全双工行为。

## 本地生成链路

已封存的本人分析 → 口播稿与术语读音 → 固定音色与适量语气控制 → 本机 TTS → 分段音频、字幕文本及定位清单。

现有 `scripts/run_review_agent.py` 已产出玩家报告；语音层应消费核验后的玩家讲解，不直接朗读原始回放包、内部工具 JSON 或未核验模型草稿。分析建议和事后经过保留各自的时间身份。

每段保留：原分析引用、本人、回合、游戏时刻、口播原文、读音文本、音色和模型版本、音频文件、音频实际时长。游戏时刻与音频播放时间是两套时钟；复盘讲解可能长于实际操作，不能直接当作同速视频旁白。

口播整理可以改长句、停顿和格式，必须保留数值、否定词、未知、前提和改选信号。音频缓存绑定文本、模型修订、参考音色和生成参数；修改一段只重做该段。

### IndexTTS 内部路线与部署约束

官方模型采用 GPT 式语音 token 生成、flow-matching 声学解码和 BigVGAN 声码器。音色参考与情感控制分离；本项目可用固定情绪向量或参考音频，不必另加载用于理解情绪文本的 QwenEmotion。

使用独立目录及 Python 3.10–3.11 环境，避免改变现有复盘项目依赖。先按官方 Windows 路径，BF16、单段顺序合成，关闭可选加速编译、DeepSpeed 和 QwenEmotion。具体命令应在固定源码提交和模型 revision 后记录；本文件不把尚未安装的命令写成现成项目入口。

主权重以外，还需要预缓存 w2v-bert、semantic codec、CAMPPlus、BigVGAN 等资源。完成后实际断网合成，才可宣称独立离线运行。

关键限制：当前官方推理代码对少于10GB显存启用低显存处理，普通 infer 路径对较长输入按标点切成约40字符短段，并默认插入200毫秒静音。官方模型卡说明跨段韵律不联合建模。应试听完整语义、接缝与音色稳定性；不未经实测调大阈值后仍宣称约6GB即可。官方A10速度不能套用到4060笔记本。

IndexTTS使用bilibili自定义许可；Qwen模型使用Apache-2.0。实施时记录许可及版本，并使用有使用权的参考音色。

### Qwen 的可复刻替代

需要直接开始时，用1.7B CustomVoice的现成中文音色和语气指令。需要原创固定音色时，按官方 Voice Design then Clone 流程：用 VoiceDesign 生成参考音频，卸载设计模型，再用 Base 构造可复用的声音提示；之后所有段落使用同一提示。无需为每段重新设计音色或训练模型。

1.7B的Windows安装、实际显存和长段稳定性须本机验证；不能用云端TTS-Flash成绩替代开源模型结果，也不能把官网首包延迟当作本机速度。

## 与 dot 交互体验的关系

声音自然与原生同时听说是两项能力。本轮先交付本机音频。如果以后需要插话，可增加本地语音检测和识别、暂停播放、向现有agent转交问题、再本机合成回答。必须处理扬声器回声、取消未播放音频和回答关联。这是可打断的模块化交互，不宣称原生全双工。
