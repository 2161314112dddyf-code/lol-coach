# 刷完这组还有多少血，这波线要不要帮

2026-11-18。对个人复盘最有用的是回答一句话：**如果你先刷完再去，队友的这波线还救得回来吗，你到场时还有多少血和技能？** 这需要把营地、兵线和到场放在同一只游戏时钟上。以下区分本轮对现有数据的回测、外部经验，以及待实现的推演。

## 刷野怎么估

**先建分营地的实测参考，再算本次决策。** 同一英雄按版本、营地与轮次、等级与技能、装备与符文、入营血蓝、惩戒、有人帮打或单打分组。记录首次有效伤害、末只或大怪死亡、奖励到账和离开营地各自的时钟，保留中断、拉脱及返回途中回血。对多怪营地尤其要写清还留没留小怪。死亡帧、吃到击杀回复后和到达线上时的血量可以不同。后续每一营从上一营留下的血蓝、等级、技能冷却和位置接着算。

同条件样本少时给相近实例、差异和粗血量；有多个独立样本再报告典型用时和血量分布。对正在打的营地，结合可见剩余野怪血、下次可用技能、宠物和惩戒，分别算保惩、交惩、立即转身。**同一条路线要同时输出时间、血蓝、惩戒、关键技能和离开位置**，才能评价到线上还有没有能力打。离开营地的选项要计可能拉脱、回血或被人接走的代价。

**剩血按收支逐段估。** 从已知起始血量出发，扣野怪实际有机会打出的攻击，加上宠物、击杀回复、药水和自身技能治疗，升级时更新血量上限。拉野少挨了一击和留在原地多挨一击要分别算，伤害与回复都有上下界时输出血量区间。复盘优先判断这个区间是否跨过到场后的危险血线；若下限也够掩护队友，本轮无需追求个位数 HP 精度。

**敌方打野用本人视角另算。** 最后露头的等级、血量、位置、可见增益和见过的营地限定候选路线。把“打完再来”“跳营直接来”“回补或换半区”能到该入口的时间分别列出。敌人重新露头、己方眼看到入口或营地可见状态变化时，才收窄范围。看不见时保留多个解释；即便最常见路线赶不到，较快的跳营路线仍可能威胁压线的人。[Reitman 对校队打野的观察，第 34 页](https://www.academia.edu/84985704/Distributed_Cognition_and_Temporal_Knowledge_in_League_of_Legends) · [Doran’s Lab 路线研究的观测粒度](https://www.doranslab.gg/articles/hacking-the-jungle.html)

**外部样本分两种用。** Zen’Kih 的首轮表按英雄、补丁、路线、惩戒次数和演示录像登记，可查某套操作有人做到过，表中没有逐营结束血量列。ROFLStats 给 EUW 16.18～16.20 实战开局分布，其定义允许只击杀营地的一只怪就记入路线。可借它们挑路线、挑样本；国服 16.22 当前英雄的典型清速与血线仍应从匹配条件的实测取得。Riot 曾在同一次更新里调整普通野怪来伤、杀怪回复、宠物回复及惩戒伤害，旧录像须留补丁标记。[Zen’Kih 原表](https://docs.google.com/spreadsheets/d/1jE8bnlnIJnmWv9pnVW9veMKRXJNaaJf5tneQB3xUkbI/edit?gid=1938238048) · [ROFLStats 统计定义](https://roflstats.com/jungle-openings) · [Riot 野区改动](https://www.leagueoflegends.com/en-us/news/game-updates/patch-26-1-notes/)

## 兵线怎么推到下一波

从一名玩家当时能见的两边前排、后排、炮车及血量起步，沿本路记录交汇位置、下一批双方援兵的到达区间、塔是否开始打兵、双方英雄能否安全接近。模拟事件依次包括接敌、攻击生效、单位死亡与换目标、援兵加入、进入塔区和塔开始清兵。首版只算到下一波交汇或当前波进塔；能连续核准后，再扩到两波。目标或小兵血量不全时跑几种与已知信息相容的开局，只报这些情况都支持的方向或分歧。

| 本人对兵线怎么做 | 给玩家算什么 |
| --- | --- |
| 离开或不碰兵 | 先看双方都不干预时哪边先清完、残兵能走到哪。本人离开而敌人留下时，另外算对方只补、主动清兵或塔前截线。 |
| 只补尾刀 | 只在普攻足以收掉目标时出手，计入出手时机、误差和对方的动作。已有兵力差、己方援兵先到或对手一直 A 兵，都会改变线往哪走。尾刀是一种操作，可以产生慢推、回推，也可能维持线位。 |
| 慢推囤线 | 选择性削弱敌方输出，尽量让己方残兵活到援兵赶上，再决定哪波交技能送塔。报告能否真的叠起来、代价是晚多久离线，以及对手能否提前削薄。 |
| 速推送塔 | 用这个英雄眼下能用的普攻和范围技能清线，计入耗蓝与重要技能冷却。比较己方残兵进塔、对方下一波拦住、对手回线截住三个时钟。整波送入后再看塔清得多快，下一波可能回推或回到中间；半推半走可能让对方留在塔外。 |

这些分支来自线上教学中的实际选择。B 站作者一拾七_17 把自己强送、叫打野、给别处压力促使对手推线列作不同解法；后者也取决于对手响应。Mobalytics 和 Dignitas 都讨论了兵线未完全送入、被塔前留住，以及承受兵线伤害的成本。大学课程项目 Wave Management Simulator 已演示尾刀、削薄和扛线，但采用固定 30 秒出兵与简化攻击，适合参考交互与反例。Uriarte 和 Ontañón 的 RTS 论文示范了从回放校准局部战斗推演的方法，其实验对象是《星际争霸》，这里没有沿用它的参数或精度。[B 站原创教学](https://www.bilibili.com/opus/850097503922552833) · [Mobalytics 兵线案例](https://mobalytics.gg/lol/guides/wave-management) · [Dignitas 控线与解线](https://dignitas.gg/articles/a-guide-to-improving-your-wave-management-in-league-of-legends) · [教学模拟器原项目](https://github.com/jonez-x/wave-management-sim/blob/main/README.md) · [Combat Models for RTS Games](https://arxiv.org/abs/1605.05305)

## 打野什么时候需要来

**从线上玩家看，先问自己能不能安全处理。** 对手把兵留在塔外，自己上去清会被打走，而下一波来后这条线还会继续卡住，值得提前叫打野一起送进塔。如果己方能把回推线留在安全位置，只需打野照一下河口；若大波将进己塔且对面有越塔能力，则请求提前反蹲或帮削薄。三类请求分别要把兵送入、保留兵线或守住人，打野到场后的动作会相反。

**从打野看，同时比较现在去、刷完去、队友自己处理。** 小汤宝长课 13:47 的既有选段里，上路线回过来，可以直接去，也可以只顺路收一组；一路刷上去，队友面对的线已经变了。工具应加上从抵达到实际出手的时间，再看本人届时的血和关键技能、敌方中野能否先来、放弃这组野会丢什么。若线上自己能送进塔，打野可以继续刷；只差有人站旁边吓退对手，帮忙露头就够了；若刷完才到已赶不上解线，就在“现在放野”和“给信号让队友先退”之间选。[前次原片核查记录](小汤宝的回合论与LoL论文_20261112.md)

**01:22 的示例。** 假设线上队友再撑一小段时间就得退，扣掉走到线上的时间后，留给潘森完成蛙的预算是 15 秒。这个 15 秒是演示条件，并非本局观察。旧算法估 13.59 秒，看起来来得及，实际剩 18.76 秒。此时可以告诉玩家“如果队友必须马上有人掩护，就现在走；若他还能自己接下一批兵，再考虑拿完蛙”。假如两种估法都会让你赶不上，就已经足够排除“打完再去”。不会把后来蛙死亡的时刻喂给事前建议。

## 接入和验收

先让现有 MCP 在同一冻结帧提供三项按需计算：① 各清营走法的结束状态；② 本路不同操作和对手回应下，本波与下一波的线位、交汇和进塔区间；③ 把前两项接上实际路线后，打野最迟几时要放下手里的事。Agent 只为会改变选择的分支取数，给一名玩家写第一步、它帮助谁及下一次应观察什么。证据不足时可以只报行动顺序或撤销信号。

| 先验哪一步 | 怎样知道有进展 |
| --- | --- |
| 营地时长和剩血 | 同构建按整局留出，分别评开打前与中途预测。比较恒定掉血、同英雄同营参考以及加入惩戒／技能的版本。报每组独立清营数、完工时间绝对误差、结束血量百分点误差、区间覆盖和宽度；像素血条保留量化误差，拉脱或中断另记。 |
| 当前波与下一波 | 用已有录像先找双方都可见、干预动作可辨认的片段。冻结当前帧，封存预测后核对下一交汇在哪一侧、是否进塔、进塔的时间区间、剩兵与增援是否同波。按整局分开，和“延续当前推向”比，公开有据可算与无法判断的比例。只有一条实际发生的走法可拿来核账，其余作为明确条件下的推演。 |
| 解线建议 | 在同一帧只改一个变量，例如打野少刷一组、对方多留一波兵、队友失去清线技能。观察建议是否随赶得上且能解决问题而翻转。先用国服 16.22 两局做开发；案例不足以校准的英雄或对位保留缺项。当前无需玩家新开训练局。 |

本轮运行的是既有下路出生时钟和两次清营的离线复算。通用刷野剩血预测、四种兵线操作的未来推演、打野解线选择尚待实现和独立实战验收。
