## 生成一段声音

在 `D:/1/yxlm/lol-coach` 中执行，输出文件名需尚不存在：

```powershell
$env:PYTHONUTF8 = '1'
& data/private/local_voice/env/Scripts/python.exe scripts/run_local_voice.py `
  --text-file data/private/local_voice/sample-review.txt `
  --reference-audio data/private/local_voice/reference-official.wav `
  --output data/private/local_voice/output/my-review.wav
```

更换音色只需把 `--reference-audio` 改为自己的本地参考音频；更换讲解只需更换 UTF-8 文本文件。当前默认 BF16、中文、CUDA、单段顺序生成，关闭 QwenEmotion、DeepSpeed、自定义CUDA编译。并非实时全双工，也没有自动把整局报告转为口播稿。

增加 `--check-only` 只检查资源，不加载模型；增加 `--verify-hashes` 对已登记源哈希的权重进行实际校验。已有 WAV、清单和未完成输出均不覆盖，失败记录保留，用新输出名重试。

生成过程设置离线环境并拦截 Python socket 连接；这证明该进程在该保护范围下运行，不等于操作系统防火墙抓包审计。失败时不回退云端或CPU。
