# ROUND-008-VALIDITY：时间预测的当前有效期

输入：同版本/同回放、实时流的路径、视野、生命/死亡、速度消息；仅处理查询时刻t前、该观察方可知内容。输出：每个实体的当前计划、条件剩余时间、失效原因及证据、终点位置报告（不是精确到达时间）。计算仅适用于收到的路线，地图导航/战斗/清兵/推塔耗时仍未知。

范围：新增因果有效期模块与独立CLI/测试；复用旧恒速算术，不改解码器、原数据、旧预测或模型契约。测试后决定是否接入，前轮准入未通过时继续保持模型calculations不变。恢复点data/private/document_backups/ROUND-008-VALIDITY-20261101。
