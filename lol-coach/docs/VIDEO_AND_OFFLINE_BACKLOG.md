# 录像实验与离线工作的依赖

更新：2026-11-01。完整操作只维护[全部实验清单](CURRENT_STAGE_EXPERIMENTS_20261101.txt)。本页解释哪些工作依赖真人材料，避免把录像当作全局开发门槛。

| 工作 | 当前结果 | 对新素材的依赖 |
| --- | --- | --- |
| 静态基础、旧版已有身份/兵线 | 已有来源与限定解析，兵线可知视图已接入 | 不重录同样初始化/身份验收 |
| 统一研究窗口与原包检查 | 四回放183窗口、80自然活动对；ec原包和竞争解释已查 | 现有约束不唯一，进一步语义需新可区分证据 |
| 新版16.21 | 容器可读；旧路径跨编号探测无可接受结果 | 简单动作/时间锚点可帮助新编码研究，先E00而非批量长录 |
| 移动计算与失效 | 软件与现有样本核查已完成；独立到达证据不足 | M提供真正起止/中断/变速证据，只限制相应精度结论 |
| 施法/冷却、连续背包、区域视野 | 仍未全解；现有观测不能唯一决定全部字段 | S/I/V分别对应成功/转好、换槽与缓存、双视角区域真值 |
| 整段分析与资料查询 | 175时刻→34检查点、141未选时刻；两次实际宿主承接完成 | 可用现有充分字段继续；不需要先解完所有冷却/视野 |
| 评测工具 | 全时刻模板、分组和标签校验已实现 | 战术质量需要独立标签；不用更多回放字节替代判断 |

先前工具准备见[OFFLINE-002](OFFLINE_EXECUTION_RESULTS.md)，实际整段接入和研究结果见[OFFLINE-003](OFFLINE_FINISH_RESULTS.md)。不要把这些已交付工具再次列成待开发，也不要把仍未解的字段改称仅仅“尚未接入”。

研究继续时需说明新增约束或反例；不能通过反复扫描相同窗口、重复同一视频或增加软件测试数来假装补足真值。更多来源和机制按本局需要扩展，J刷野实测优先复用条件完整的人类材料，不在当前要求用户穷举录制。
