## 验收顺序与完成条件

| 工作项 | 解析器应从目标 ROFL 导出的结果 | 开工状态及核对办法 |
| --- | --- | --- |
| 容器、身份与时钟 | 构建、时间基准、实体与队伍绑定，有依据的地图／模式 | 16.22 本样本容器已读通，局中身份待确认。用整局名册和局内独立身份记录对应同一实体，再核对后续事件时间。 |
| 英雄状态、移动与可见性 | 生命、资源、等级、经验、金币、生死与击杀参与者、已观测的位置／路径、相对观察队伍的进出视野 | 16.20 有限定样本输出。逐项核实新版，抽查更新、生死、路径改变、消失和重新可见的片段，保留采样时间。 |
| 技能和召唤师技能 | 施放者、技能、成功释放时间、可确认的冷却状态与变化，相关关键控制的命中／解除 | 对拉克丝两发与未施放片段作正反核对。另查技能标识、实际计时字段；空地样本不用于验命中。闪现等有不同实例时逐项核对。 |
| 回城、关键装备 | 回城开始／取消／完成，物品归属、取得／移除时间，可区分的交易类别 | 用有对应事件的整局，用回城读条、位置、背包、金币变化或其他独立数据区分候选。 |
| 三路小兵、防御塔与地图资源 | 兵种、阵营、线路、生命及路径，塔的身份／血量／摧毁，营地和史诗目标的实体、实际出生／击杀／再次出生及可确认的击杀方 | 先查整局中实际出现的事件，对照地图、击杀公告、可核验的事件日志或回放画面。由规则计算的刷新时间另列。 |
| 守卫与区域视野（按字段清单的适用场景） | 守卫类型、阵营、位置、放置和拆除／到期事件，有直接记录的区域更新 | 对比物体生命周期与对应观察方可见变化。已解的英雄进出视野单独核算。声明覆盖的场景必须有证据。 |
