## 先适配旧版已解的字段

- **身份、移动和英雄状态。** 把局内对象 ID 绑到英雄和队伍，再适配位置／路径、移速、生命、资源、等级、经验、金币、生死、击杀与英雄对指定队伍的显隐。16.20 限定样本已有输出，16.22 的局内身份绑定优先级最高，否则后续动作无法归人。
- **兵和塔。** 复用小兵 ID、阵营、兵种、路径、血量、零血，以及塔 ID、阵营、血量与摧毁的旧版结果。补 16.22 峡谷三路覆盖。若按出生点和路径即可稳定分路，直接计算线路，无须搜一个“上中下路”字节。[旧版基础字段](../reports/replay_ten_validation.md) · [兵线实测](LANE_WAVE_RESULTS.md)

## 哪些不用专门逆向

| 信息 | 取舍与原因 |
|---|---|
| 鼠标轨迹、具体按键、冷却中空按次数、药水放第几格 | 这些细节不改变上述回合的行动选择。底层仍可用槽号恢复物品持有与消耗。专门讲走位或连招时另定微操问题。 |
| 十人每招每秒的精确 CD、每次普攻的伤害、全图每格迷雾、每个兵折多少金币 | 首轮复盘不用一律收齐。拆解关键控制、绕眼、漏炮车等具体问题时，再提高对应字段的精度。 |
| 英雄技能说明、地图通行、物价配方、版本刷新规则 | 决策需要这些知识，可按本局构建和地图查资料。当前持有装备、已交技能、目标是否被击杀仍从对局取证。 |
| 线权、可能赶到的人数、谁先手谁跟进、刷完还能否赶上、对手可能回城 | 属于分析结果。用当时观测和版本资料推算，写出会让判断失效的条件。例如猴子的慢推可观察，“他想回城”是作者对意图的推断。 |
| 雾中敌人真位置、尚未发生的团战结果、结算装备与胜负 | 仅在回看结果时使用。评价出发时的选择，只能使用截止当时己方可知的信息。若问题涉及沟通，可记录已有信号；单凭队友走向无法确认其意图、承诺或注意力。 |
