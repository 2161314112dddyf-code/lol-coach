## 本轮真正增加了什么

本批有 **74 个去重资源，29 个读到正文或相关楼层，21 个形成条件候选**。筛选其中 **15 个来源**，新增 K17—K24 八张卡，并补充 K05、K15。手册现为 **24 张卡、32 份来源档案**，版本 `2026-11-19.2`。资源目录另有待读入口，不能将其算作已看视频或已采纳知识。

中文论坛占本批51个讨论串，其中21个读到相关正文。大陆平台重点查虎扑、贴吧、B站、知乎，也查PTT、巴哈。只有明确自述国服经历的文章才登记这一语境，作者段位仍未认证。多数长文来自旧版本，因此抽取的是“该检查什么、什么条件会改判”，不搬用旧装备、伤害、刷新秒数或保证胜率。

## 八个补充问题

| 卡 | 什么时候问 | 要接上的判断与反例 |
| --- | --- | --- |
| K17 换血后还剩什么 | 刚换血，或准备承伤抢线 | 看回复储备、关键技能及兵线是否改变。拿到先动后低血无力支援，应另比回城或短暂施压；也不能一律拒绝用血换有效机会。 |
| K18 捏技能的威胁 | 对手补刀、关键技能交出、本人考虑换血 | 对手给机会才比较短换与延长交战；不给机会可保留威胁争兵线。一个敌人空技能不等于其搭档没有反制。 |
| K19 强势所需状态 | 升级、补装、召唤物或关键资源改变 | 检查动作依赖的资源此刻是否存在。同英雄同等级不能默认墓、触手、被动等都已准备好；未知就保留条件。 |
| K20 更早的准备机会 | 当前真的发生支援冲突 | 当前接不接与上一波能否做线分别判断。只用早先时刻已有证据回看，不能拿后来敌方出现的位置责怪玩家此前没预判。 |
| K21 刷野路线的目的 | 开始一轮、营地结束、目标路改变 | 从能兑现的抓人、护送或反蹲任务倒推终点。被压塔的队友未必能跟；目标消失后保留刷野或回补备选。 |
| K22 换线由谁接管 | 外塔变化、回补空档或换接请求 | 同时比较交换后两条线。队友未接管就不能把理想分线当成已发生；本人要有不挤线、不放空原线的备选。 |
| K23 本人的团战职责 | 接近交战，或关键技能、先手者变化 | 给本人安排最相关的第一件事：先手、跟进、保护或等窗口。理论连招打满不证明能出手，等待本身的损失也要比较。 |
| K24 出装要完成什么 | 计划购买、装备成型或对方防装变化 | 先说需补续航、接近、爆发或持续输出，再查本版本物品与现金。提高留人却失去队伍所需伤害，可能不符合本局任务。 |

## 论坛分歧如何留下来

| 分歧 | 保留的条件 | 没有采纳的口号 |
| --- | --- | --- |
| 控线压补刀，还是推线做地图 | 看能否维持、承伤与对手离线造成的影响；可以从控线转囤线，再确认送塔。已补K05。 | 控线永远最赚；优势就一定推线游走。 |
| 塔下接兵，还是先帮打野 | 把当前可行选择与更早准备机会分开，比较本人到场能做什么。 | 二打一必赚；不支援就是错；事后一句“早该推线”抹掉所有条件。 |
| 发信号后可否按配合计划走 | 请求、实际响应与有效接应是不同状态。没回应时保留本人备选，已补K15。 | 发了就算同意；沉默就代表拒绝；持续提醒全队才算会沟通。 |

## 怎样接到已有链路

依然是 **当前事件 → 本人可知事实 → 按需读取相关卡 → 工具核条件 → 比较行动 → 条件后果与下一次观察**。新卡在既有MCP `get_reference` 中以 `knowledge:K17` 等ID读取。不会把74个资源正文一起塞进上下文，也不另建一套Agent。

例如“换血后把线推了，然后游走”，现在应拆为：K17核剩余状态；K04确认是否真送塔；K09比较到场贡献与原路损失；若涉及转线再读K22。完成一步后进入下一分支，条件没成立就缩短、改选或回补。**本例只是条件链示范，不是一场已验证的实局。**
