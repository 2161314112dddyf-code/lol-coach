# 击杀以后，先把下一波也想清楚

更新于 2026-11-19。面向端游召唤师峡谷的个人赛后复盘。本篇把原作者经验整理成有条件的行动分支，供 Agent 按需读取。它不提供未经校准的进塔秒数、必亏几只兵或游走成功率。

**一次分析至少接住两次状态变化。** 击杀后怎样处理眼前兵线，处理后能离开多久，回来时在哪里接下一波。选择会因对手回线、剩余辅助、打野露头和队友响应而改变。后文的分支设计是项目归纳，来源支持具体经验，并不等于作者验证过这套程序。

## 玩家先看这一页

| 眼下发生了什么 | 先做的判断 | 可能的第一步 | 完成后再看什么 |
| --- | --- | --- | --- |
| 杀了对线的人 | 本人剩血蓝、关键技能、对方谁还活着、双方线往哪走 | 留住回推线、送塔回城或继续囤线 | 对方回来前能否完成，自己的装备何时兑现 |
| 想回城，但线推了一半 | 剩余清线与护送进塔是否赶得上，敌人能否截住 | 继续送完，或停止追加投入并接受这波损失 | 回线后是否要请人解线 |
| 大波已经进塔 | 是否整波进入，塔清兵与下一波相遇的先后 | 回城、短游走、掩护队友或点塔 | 对手清线、回线与自己的回程期限 |
| 线向自己来 | 能否安全接住，敌人会不会囤大波越塔 | 接线或削薄，必要时请求掩护 | 下波会继续回推、停住还是转为己方推进 |

## 每次先取哪些事实

只查会改变这次选择的信息。自己在线上安稳补刀时，不需要把全队重新分析一遍。

- **本人能做多少事**。生死、血蓝、可用清线与自保技能、装备和待花金币。刚拿到的钱尚未购买装备，不能直接加进当前战力。
- **眼前这一波**。可见兵种、数量与残血、交战位置、塔是否已经攻击、对方是否仍能补刀或削线。上一波残兵和远处下一批援兵分开记录。
- **下一波与回线**。双方下一批兵的到达区间，对手死亡与回城证据、传送可用性的已知边界。无法确认传送时保留有、无两种情况。
- **能打断计划的人**。剩余对线者、可见打野、中辅动向、入口视野、己方搭档是否真在帮。最后露头和已发支援信号各自保留时间，不改写成当前到场。

这些字段构成项目的取数设计。旧教学中的兵数口诀、复活时间、固定回城窗口要经过本局版本核对。例如 Riot 26.1 已修改出兵间隔、移速和兵线组成，旧文的全程 30 秒出兵不能直接进入计算。[官方 26.1 的 Minions 段](https://www.leagueoflegends.com/en-us/news/game-updates/patch-26-1-notes/)

## 六张连续决策卡

### WAVE-01　击杀后先定兵线，再定回城

**触发。** 本人参与的线上交手结束，或对位死亡、被打回城。先确认交手确实结束，杀了辅助不代表 ADC 也失去阻拦能力。

**比较三条路。** 本来就缓慢向己方来的线，先比较直接回补。己方有能力在敌人回来前送塔，比较送完再回。状态够、暂时不急于离线且能够保护残兵，比较继续囤线。对每条都保留不处理兵线直接退出的代价，避免只给“再多赚一点”的方案。

**下一节点。** 回城完成后，从新装备、自己的回线时间与新线位重新决定。继续留线则在敌人回线、下一批兵加入或己方关键技能交掉时重算。

**反例与未知。** 残血缺蓝、敌方传送、剩余对线者清线很快、打野可赶到，都可能让送塔方案失效。没有完整双方兵线时给条件式建议，不能写“这波肯定回推”。击杀后保留回推线和送塔回补两种思路在原文都有实例，具体优先级需要本局判断。[一拾七_17](https://www.bilibili.com/opus/850097503922552833) · [Wrasul 的击杀辅助后回城问答](https://www.bilibili.com/opus/1070207456794116113) · [Yeboy 的 Solo Kill in Lane 段](https://dignitas.gg/articles/pressing-the-advantage)

### WAVE-02　四种操作分别会留下什么

| 本人操作 | 必须成立的条件 | 需要推演的结果 | 使原计划失效的变化 |
| --- | --- | --- | --- |
| 不碰兵、离开 | 允许当前残兵自行交战，或继续留场代价更大 | 无人干预的自然推进，以及对手留下后主动处理两条分支 | 对手快速清兵、塔开始攻击、有人截线 |
| 只补尾刀 | 能接近目标且不会为保刀付出过高血量 | 这一刀会提前结束目标输出，线位可能继续移动 | 己方残兵迅速变多，对手改变攻击频率 |
| 慢推囤线 | 有时间保住残兵，援兵能赶上，对手难以削薄 | 囤了几批，何时必须改速推，囤线期间本人被留在线上的代价 | 对手清线技能转好、支援窗口提前关闭、残兵积不起来 |
| 速推送塔 | 清线技能与血蓝足够，能够护送，赶得上敌人或下波阻拦前的窗口 | 送塔成功、塔外被截住、下波加入导致多推一波 | 清线技能打空、搭档离开、敌人提早回来 |

**尾刀是一种动作，控线和慢推是需要验证的结果。** 是否囤起来还受交汇点、残血、援兵先后与对方干预影响。Agent 不能把选项名称直接当作未来状态。上表是项目的统一比较方式，来源分别提醒尾刀也会推动兵线、囤兵需要保留存活兵力、己方增援先到会改变平衡。[Chillwang](https://dignitas.gg/articles/Advanced-guide-Freezing-your-lane) · [Ahrivve 的 Slow Pushing 段](https://dignitas.gg/articles/a-guide-to-improving-your-wave-management-in-league-of-legends) · [AIIen 的推速与大兵线段](https://talk.op.gg/s/lol/tip/6474419/?tl=zh-CN)

### WAVE-03　送塔成功后，再判断回推和可用时间

**完成条件。** 分开记录“清掉眼前敌兵”“己兵正在前进”“兵线完整进入塔区”。只有前一项时，后两项仍可能被新兵或敌人截断。

**下一节点。** 整波送塔后，至少保留两种未来。如果塔下残兵还在，后续援兵在近塔位置加入，可能产生向己方来的线。如果塔下兵先被清光，后续波次可能重新交汇。再加入敌人快速清、只补刀、扛线拖延三种实际可能的响应。没有相应证据时，输出方向假设与需要看的变化。

**反例与未知。** 对手的清线速度、塔下残兵、下一批兵的到达不清楚时，不能发放固定时长的“免费游走”。即使兵线创造了空档，走到目的地再回线也会消耗它。原作者对进塔后交汇的区分用于提出分支，具体波次结果需由本局数据验证。[AIIen 的兵线结构、交汇点与回城段](https://talk.op.gg/s/lol/tip/6474419/?tl=zh-CN) · [Wrasul 的囤线进塔后问答](https://www.bilibili.com/opus/1070207456794116113)

### WAVE-04　卡线、削薄和打野解线是三种请求

**能控住时。** 本人有足够状态，能阻止对手强清，线留在己塔外可以让对手前来补刀承担风险。每次新兵加入都要检查是否需要削薄。卡线也会给对手离线行动的空间，需要提醒受影响的队友。

**控不住时。** 大波向己方塔来且敌人具备越塔条件，先比较削薄、守塔接线、提前撤离，向打野请求掩护。低血量身体扛兵可能直接把自己送进对方的击杀范围。

**被卡住时。** 本人无法安全接近敌塔外兵线，下一波仍将继续损失，才提出具体解线请求。打野若只需站在旁边施压，就不必假定要打架。需要合力清兵时，请求目标是送进塔并让线上玩家完成回补。

**下一节点。** 只在打野实际赶到并具备威慑或清线能力时切换计划。没有响应就继续比较自己强送、等待或去别处兑现机会。后者能否迫使对手推线仍是未知，回来看线才能确认。[Ahrivve 的控线、削薄及解线段](https://dignitas.gg/articles/a-guide-to-improving-your-wave-management-in-league-of-legends) · [一拾七_17 的解线办法](https://www.bilibili.com/opus/850097503922552833) · [小雪呼呼的中期边线协同](https://www.bilibili.com/opus/909355412530135056)

### WAVE-05　推完以后，回城、点塔、游走分别重新报价

**回城。** 比较未花金币能换到的能力、恢复状态和回程接线。已经有合适补给窗口，继续贪一轮就要重新承担被打断与晚回线的成本。

**点塔。** 查眼下能打多少、剩余对手何时能阻拦、这会不会耗掉回补窗口。敌人刚死亡创造的是有限的压力空档，不能无限续下去。

**游走或掩护打野。** 写明目的地的具体收益，可能是救人、解线、获得入口视野或护送入野。查看本人到场时事情是否仍有改变空间，再比较回程损失。对方能放弃兵线追随，不能假定一定被锁在塔下。

**辅助的单独检查。** ADC 还能安全站在哪里，面对谁，是否能接下一波。辅助已发信号而 ADC 未动时，行动方案要保留本人先折返或缩短游走的选项。双方能否承接输出本来就取决于位置，线上平行站位的教学可用于识别这一条件。[Tyreals 的下路站位段](https://www.bilibili.com/opus/451197696109889255) · [小雪呼呼的中期思路](https://www.bilibili.com/opus/909355412530135056) · [Yeboy 对胜利后追加收益的限制](https://dignitas.gg/articles/pressing-the-advantage)

### WAVE-06　下一波到了，原计划允许被推翻

**触发。** 下一批兵加入、对手回来、清线者更换、关键技能恢复或己方队友改变位置。只更新受影响的比较，避免每秒重做整张地图。

先核对上一步留下的实际状态。成功进塔就继续看补给与回线。塔外被截则转入解线。对手回推大波则看接线或防越塔。自己仍囤有大波时才继续比较护送、消耗和越塔，不能因为先前计划“囤两波”就默认已囤成。

这是项目从多份教学中整理的阶段转换。战术经验提出合理的下一问，工具和观察回答当前是否符合。回放之后发生了什么可用于核账，只能在封存事前建议后读取，不能倒灌进最初的选择。[FakeGod 的控线到囤线转换](https://dignitas.gg/articles/top-lane-essentials-with-fakegod) · [AIIen 的波次讨论](https://talk.op.gg/s/lol/tip/6474419/?tl=zh-CN)

## 给 Agent 的调用约定

每次挑与事件相关的卡，输出简短、可检查的依据，不要求向玩家展示冗长的内部推理。最低内容为本人第一步、希望留下的状态、对手怎样回应会使它失败、下一次观察点。

| 应保存的内容 | 用途 |
| --- | --- |
| 卡 ID、资料版本、来源访问级别 | 确保建议能追溯，标题不会变成正文证据 |
| 当前可见事实和时间，必要的未知 | 固定本人视角，避免利用未来与隐藏信息 |
| 适用前提与不适用条件 | 经验进入本局之前先过条件判断 |
| 当前动作与所需时间、状态 | 交给已有工具按需计算，空值保留 |
| 动作后的候选状态 | 分开已观测结果、推演和假设 |
| 下一触发与改选办法 | 让击杀、兵线、回补和再次出门连续起来 |
| 只改变哪一项会翻转建议 | 检查它是否真正使用证据 |

当前工程已有的兵线分支与出生时钟可提供线位、波次和假设入口。此手册不升级其精度声明。若缺本波清线与塔击推演，就用“能否赶在下波拦住之前送塔”的条件句，并指出下一步要检查哪一项。不要生成凭空的 12 秒、三只兵或固定成功率。[既有数据边界与验收](../回合复盘方案_v0.1/刷野血线与兵线推演_20261118.md)

**示例为条件示例，未冒充本局实况。** 你是辅助，刚击杀敌辅，己方 ADC 准备清线。先看敌方 ADC 是否还能阻止送塔，以及你们的剩余状态。能够完整送塔就帮忙完成，再看自己能否短走去做入口视野；如果 ADC 清线后要回补，就从双方补给后的路线重新规划。敌方下一波先到、自己又没有清线能力时，停止把“再帮推一下”当作既定收益，比较退出与请求解线。假如敌方打野在此时露头，这个新事件足以触发改选，无需继续执行原定游走。
