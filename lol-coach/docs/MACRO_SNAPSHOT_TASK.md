# SNAP-001：指定时刻的大局观输入 v1

用户要求：整合结构，支持一个时刻的大局观分析。范围为现有四类解码输出的离线合并；不新增协议实验、前端、模型调用或游戏操作。

输入：同一回放的 replay_ten / replay_state / replay_inventory / replay_vision 完整导出，时刻、观察队伍、可选本人实体。输出：macro-snapshot/v1 JSON 和中文摘要。已有解码器保持原样；新增聚合模块、CLI、测试及真实样本。

信息边界：队伍共享可见信息，非相机注意力模拟；金币/经验/装备操作仅可选本人开放。两边完整阵容进入机制关系上下文。生命/位置均保留观测时间和证据，敌方只接纳可见期间的新采样。地图/技能/行动耗时/经验没有匹配证据时保留缺口。

| 验收 | Given / When / Then |
| --- | --- |
| SNAP-01 | 同版本同源四份输出，查询合法 t → 双方阵容、已知状态、历史观测、近期事件、基础缺口、行动比较契约在一个结构中；所有字段可追溯。 |
| SNAP-02 | 追加 t 后事件或改变结算 → 查询结果不变；隐藏状态不更新历史观测，重新可见不复用隐藏期间数值，同帧按包偏移排序。 |
| SNAP-03 | 缺记录/未知阵营/完整背包不可恢复 → 明确 unknown，不补零、不补结算，不输出隐藏位置、移动终点或敌方私有经济。 |
| SNAP-04 | 输入不同源/版本/前缀不足或非法时刻 → 拒绝合并；真实回放 CLI 运行，既有测试回归。 |

实现顺序：保存恢复点 → 统一证据/前缀过滤 → 聚合英雄及双方关系 → CLI/摘要 → 合成边界检查、真实前缀检查 → 状态交接。

检查命令：`.venv/Scripts/python.exe -m pytest -q --basetemp=data/tmp/<本轮未存在目录>`；`scripts/verify_macro_snapshot.py`。合成测试验证软件边界，真实样本验证现有输出的集成，不充当独立 UI 语义复核。
