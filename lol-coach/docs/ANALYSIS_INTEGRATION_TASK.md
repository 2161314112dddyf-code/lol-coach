# INT-001 连续整合与缺口实验

授权：用户要求将分析所需信息一并弄出、持续完成可自主处理的工作。沿用基础 F01–F06、TL-001 和既有逆向目标，不要求补录或重新校准。

输入：四类已解回放输出、敌塔身份与视野、固定 16.20.1 官方缓存、真人经验缓存、现有移动视频核对报告、背包操作与关键帧。原始素材只读。

输出：统一离线分析入口（JSON、可读报告、来源清单）、行动时间线与有条件耗时计算、背包关键帧时间语义实验、剩余缺口报告。未解字段保留未知，不生成战术评分或自动完整复盘。

| 验收 | Given / When / Then | 检查 |
| --- | --- | --- |
| INT-01 | 同一回放在时刻 t 聚合敌塔观测；仅使用此前身份及可见期间生命，隐藏值只留历史；错来源/版本拒绝 | 合成边界与真实两队查询 |
| INT-02 | 本局阵容关联官方缓存与历史经验；返回来源、版本、队友/对手关系；静态参数不当当前技能状态 | 缓存哈希、真实十人输出、篡改拒绝 |
| INT-03 | 既有移动证据生成时间线；计划、单点候选、视频实测分列，路线除以速度仅为条件计算 | 真实报告及公式边界检查 |
| INT-04 | 比较背包关键帧与不同时间前缀的操作状态；保留全部试验分母与反例，禁止自动重定时 | 真实全样本实验、原输入哈希 |
| INT-05 | 联合 CLI 可离线运行，输出覆盖情况与未完成项；未来包不改变时刻输入，原文件不改写 | 集成运行、前缀不变性与回归 |

修改范围：新增聚合、动作、实验模块/脚本/测试；更新入口、状态和总结；如发现已有文本编码损坏，按已有生成器和缓存重建并记录。恢复点 reports/analysis_integration_baseline/manifest.json；新产物使用新路径，不覆盖旧验收结果。自检由 Codex 执行，人工签署和独立复核未执行。

有限研究：背包时间偏移与稳定槽位/事件时间约束；刷野第一手资源的条件完整性。不能解出即留下可复现反例和具体缺字段，继续整合其他成果，不把负结果冒充协议成功。
