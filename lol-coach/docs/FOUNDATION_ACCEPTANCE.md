## 1. 已批准的范围选择（保留原提案内容）

建议将基础 v0.1 定为：**建立可查询、可追溯的地图、机制、动作和经验基础，并打通一个有限案例；按覆盖范围进入临场信息阶段。** 不以“模型看起来懂游戏”或测试数量作为完成标准。

以下是本草案提出的选择，用户可以整份批准，也可以按编号修改：

- **D1 地图与版本**：冻结 Map11/Default、本地客户端 16.20.824.8524 和静态数据 16.20.1。分别保存版本，不默认两个版本的所有字段兼容。不扩展其他地图、模式或补丁。
- **D2 英雄覆盖**：基础属性和原始技能描述覆盖该静态版本的完整英雄目录；首个深入机制案例建议选现有录像中的潘森。完成被动与四个技能的机制卡，以及至少一个队友配合、一个对手限制的具体英雄交互案例。艾翁已有数据继续复用，但不要求用户玩艾翁，也不把艾翁作为项目继续的条件。具体交互对象由可核验资料选择，记录在同一案例清单。
- **D3 空间与时间能力**：首版支持坐标/地图标记查询、已有计划路线核查、行动时间线、带明确条件的步行耗时计算，以及实测动作记录检索。任意起终点的完整导航、动态碰撞、战斗和刷野全过程模拟不列入这一版。
- **D4 真人与动作资料**：在现有移动耗时样本之外，取得一条条件完整的真实刷野记录；读懂并形成两条真人经验卡，分别覆盖“继续发育”和“转向支援或争夺”的判断条件。可以来自同一份合格资料，不为凑数量另找作者；必须有可核查正文或视频片段，链接目录不算交付。
- **D5 阶段衔接**：下面六项达标后，先接入有限案例需要的临场信息。之后扩展到真实对局时，补齐会改变该局结论的己方、队友及对手机制；未覆盖部分不得由模型记忆补成事实。不要求此刻做完整英雄百科。
- **D6 执行与停止**：批准后由 Codex 连续完成可自主完成的部分；不逐条找用户确认，不再要求补拍当前移动录像。新费用、权限、确实拿不到的必要资料或业务范围变更才交用户处理。

这些选择限定第一版的业务范围。后续完整赛后决策复盘目标不变；首版不声称已经具备完整行动预测能力。

**F-02 的验收边界：**当前坐标原点、SRX_3 选择与路径是有证据支持的分析基础，不能升级成所有时刻的真实轨迹或完整运行时可通行证明。基础图未知标记、英雄碰撞半径和动态障碍保留未知。遇到依赖这些条件的查询，应说明无法判断。

**F-04 的验收边界：**观测耗时、给定假设的计算、相似实测记录和对未来动作的预测必须是不同类型。现有 2.3–2.6 秒区间只证明该段观测；不能据此宣称一般移动预测误差小于某个百分比。恒速计算不支持变速或重规划期间的总耗时预测。本版刷野提供实测参照，跨装备、操作、版本的自动推演另立任务。这里需要审批的是能力边界，不能靠一个很宽的估计区间把预测算作通过。

## 3. 用什么证据验收，什么时候不再测

固定验收包由现有移动材料、冻结版本数据、D2 的机制案例以及 D4 的公开资料组成。新增资料找到后先登记内容哈希、版本和片段定位，再运行对应验收；不根据输出好坏挑换样本。

每项只做：已有证据复核、尚缺的正常结果检查，以及必要的边界/反例检查。共用反例可以合并：损坏缓存不能当成功；替换路线不能当到达；未知条件不能填 0；旧版本经验不能当本局事实。不规定为了数量凑测试，也不把 107 个软件测试通过等同于六项业务验收通过。

每条结果记录验收 ID、目标版本、PASS/FAIL/INSUFFICIENT_EVIDENCE、证据路径、来源/证据层级、适用范围和缺口；只有用户明确批准不适用才使用 NOT_APPLICABLE。合成测试验证程序行为，真实资料支撑游戏结论，二者分开。

**停止规则：某项达到上述约定且没有已知阻断反例，就冻结该项，转下一项。** 没有代码/数据变化、失败或新反例时，不重复验证。新增“最好再测一下”必须指出具体违反哪条验收、会改变什么结论。若是更高精度、更多英雄或更多场景，先提交有限范围变更，不能暗中抬高本版门槛。

核心正向成果必须存在：只有 unknown、只有拒绝回答、只有结构或链接，都不能满足该项。某项拿不到证据时，写明缺的字段和已经尝试的入口，继续其他模块；不能偷偷删掉要求或宣称整体完成。

Codex 负责实现、自检和说明证据；用户负责本草案范围审批与阶段业务验收。没有独立复核就明确写未执行，不虚构签署。日常实现选择、可逆修复和约定内自测由 Codex 完成。

真正需要接管的情形仅包括：必要资料经公开入口和已有本地资料仍不可得；需要新的授权/费用；发现必须改变已批准范围的矛盾；提交阶段结果请用户验收。届时列出阻断 ID、现有证据和可选处理，不泛泛要求“再给个视频”。部分公开资料不可访问时先尝试同类替代资料，不直接停掉整个项目。

执行范围：现有 Python 项目、只读素材、公开资料缓存、规范化数据、针对性测试和报告。无前端、微调、付费调用、自动游戏操作或素材上传。工作量以本表交付物为限；无已批准的金额或 Token 数额，记 unknown。发现需要范围外工作时先保留成果，交用户决定。
