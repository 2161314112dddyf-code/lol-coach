# 现在模型能读到什么兵线

**已经接入模型并用三个真实时刻实际解读。** 输入包括：双方已知可见兵数与兵种、最新复制生命、估计位置与运动方向、前后兵团、静态塔位参照，以及最近受伤和零血变化。

一个真实例子，观察队伍100：

| 时刻 | 模型读取出的兵线情况 |
| --- | --- |
| 4:43 | 己方3近战＋3远程仍在己方外塔附近；可见敌方2近战，其中1只位置暂缺 |
| 4:53 | 己方六兵继续向前；当前可知视图没有活敌兵，近3秒有两只敌方远程兵归零；不等于全图无敌兵 |
| 5:00 | 前方只剩3只远程兵；后方另有3近战＋2远程＋1炮车，不能把炮车当作已经到前方 |

5:00实际模型答案还明确使用了9只兵的最新复制生命，并保留同步延迟；没有根据塔位猜攻击者，也没有把4条损失分量当成4次攻击。

验证依据：15个关键帧活兵集合全部吻合；229个位置核对中，前推误差中位2.61、P90 30.33游戏单位；2,857个非致死掉血区间与解析损失分量吻合。位置是估计，遇到突变不保证准确，隐藏单位不补成全知。**最终873项代码测试通过；3份实际模型答案的数量、分组和引用核对通过。** 这不是独立比赛战术准确率。

现有`analysis.py context`及`reasoning.py prepare`已自动接入本地兵线导出。`frame.json`里的`lane_fact_ids`指向模型可用字段，原始包和全知研究材料留在审计侧。
