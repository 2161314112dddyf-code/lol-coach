# 知识手册怎样接入连续复盘

任务 `KNOWLEDGE-CHAIN-01`，手册版本 `2026-11-19.1`。用户要求上网积累可用经验，并处理击杀、兵线、回补等问题连续出现时的判断。已在现有单人 Agent 和只读 MCP 中实现，无需新增录像或模型训练。

入口是[简版手册](../docs/knowledge/README.md)。本轮实际核读14篇不同作者正文的相关段落，另沿用3部既有小汤宝选段。16张条件卡的17份来源档案逐项记录读取范围、日期、版本边界与未采用的绝对化说法。部分视频网页412或字幕为空，未写成新观看成功。

## 已实现

新正式会话先固定知识版本和正文哈希，再写冻结包、启动MCP。模型只见短目录，按需读取卡片。手册提出条件问题，已有工具提供本局事实、时间、机制与视野证据。新卡引用在正式运行中必须有本次成功的 `get_reference` 读取。

答卷新增 `follow_through`，绑定首选并表达继续当前动作的后果。每步有本人动作、条件下预期、复查时机、确认后的下一步、受阻后的备选及证据。最多三步，不自动把预期执行成事实。下一帧保留这段计划，历史事实与当前事实分开。旧知识卡的版本、描述符和内容哈希随历史计划保留，避免同名卡更新后改变旧建议含义。

普通玩家卡和安静个人帧都能显示简短后续。安静帧不新增全队沟通或扫图要求。原有冻结答卷仍使用原有契约，未回填新字段。

## 运行

原有 `scripts.run_review_agent` 命令自动启用手册，继续使用已配好的文件或本机模型后端。`probe` 仅验证工具，不能算模型已使用知识。操作见[运行手册](../README.md#复跑个人行动与赛后执行核对)。

```powershell
# 在 lol-coach 目录，离线跑知识回归
.venv/Scripts/python.exe -m pytest tests/test_coaching_knowledge.py -q

# 同时检查原有 MCP，使用本机既有 MCP Python
$env:REVIEW_MCP_PYTHON = (Resolve-Path 'data/private/agent_study_current/mcp-env/Scripts/python.exe').Path
.venv/Scripts/python.exe -m pytest -q --basetemp ('data/private/knowledge-check-' + (New-Guid))
```

## 仍然保留的缺口

缺双方兵线交战、增援、塔击的通用精确预测时，不能报准确进塔秒数、损兵数或必然回推。通用刷后血蓝也没有被这本手册解决。当前可以给出下一步需要确认的条件与备选，不将这些缺口变成统一退让。

这是Codex开发侧实现与自检，未做真人盲评或未见对局的统计评价。下一项可独立推进的是使用已有回放封存更多条件预测，再核对实际分支；需要扩大的是评阅覆盖，而非把新录像作为使用手册的前置条件。费用和Token统计未取得，人工验收未签署。本轮未提交或推送GitHub，私人回放与运行产物仍留本地。
